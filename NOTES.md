# CBS OData v4 — probe findings (2026-10-10)
- Base `https://datasets.cbs.nl/odata/v1`. Root sets: `Datasets`, `Catalogs` (only `CBS`), `ReleaseCalendar`.
- `Datasets` fields: Identifier, Title, Description (long, NL), Status (Regulier 1293 / Gediscontinueerd 3575 / Vervallen 22), Modified, ObservationCount, Catalog. No explicit period field: the period is in Description ("Gegevens beschikbaar vanaf").
- `/CBS/{id}` lists the dataset's sets. Code-set names come from `Dimensions[].CodesUrl` (e.g. `RegioSCodes`, `PeriodenCodes`). Dimensions have `Identifier, Title, Kind` (GeoDimension/TimeDimension/Dimension).
- `MeasureCodes`: Identifier (e.g. `M000098`), Title, Unit, Decimals, Description (long). `{Dim}Codes`: Identifier, Title, DimensionGroupId, Status.
- `Properties` (singleton): Identifier, Title, Description (very long; truncate).
- `Observations`: Id, Measure, Value (float|null), StringValue, ValueAttribute ("None" or a footnote flag), plus one column per dimension code.
- Working: `$filter` (eq/ne/and/or, `contains(tolower(Title),'x')`), `$select`, `$top`, `$skip`, `$orderby=Identifier desc`, `$count=true` (+`$top=0` = count only).
- Escape quotes by doubling (`'Regio''s'`). Wrap OR groups in parens: `(RegioS eq 'A') and (Perioden eq 'X' or Perioden eq 'Y')`.
- Paging: server page = 100,000 rows, then `@odata.nextLink` (`$skip`). Big tables: 37230ned has 2.9M rows, so always filter.
- Periods: `2024JJ00` (year), `2026MM08` (month), `2024KW01` (quarter). The latest period = PeriodenCodes `$orderby=Identifier desc&$top=1`.
- Errors: a bad property gives JSON `{"error":{"message":"Could not find a property named 'Regio'..."}}`. An unknown dataset gives 404.
- Population: `37230ned` "Bevolkingsontwikkeling; regio per maand", measure `M000098`. Amsterdam = `GM0363`.
- `ReleaseCalendar`: DatasetIdentifier, ReleaseDate only, so join it to Datasets for titles.
- Search: `$search` is silently ignored (returns all rows). Only substring `contains()` on Title/Description works, with no ranking or stemming. All 4,890 datasets are Dutch, so English terms return 0. Full catalog: ~0.7MB (titles) or 6.4MB (with descriptions), ~1.7s.
